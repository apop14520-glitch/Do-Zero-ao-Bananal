# Do Zero ao Bananal

Site oficial do manual digital **Do Zero ao Bananal**, do Criatório Araguaia.

O projeto inclui manual navegável, progresso local, checklist, calculadoras, cronograma e integração configurável com checkout da Hotmart.

## Publicação no Netlify

Este repositório está pronto para publicação como site estático. Use a raiz do repositório como diretório de publicação e não configure comando de build.
